# Data availability and repository boundaries

This repository contains code, frozen configuration/manifests, optimisation
summaries, a study log, and aggregate per-consultation error counts/rates.

It does **not** redistribute source audio, reference transcripts, model weights,
or local clinical recordings. Fareez and PriMock57 must be obtained from their
original publications and used under their respective terms. Public corpus case
identifiers are retained only to support paired verification of aggregate
metrics; no transcript text is included in the committed result tables.

The repository is not a clinical deployment package. It documents a research
configuration-selection analysis on simulated consultations.
